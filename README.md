# Intelligent Spoilage-Risk Forecasting in IoT-Enabled Cold Storage — Reproducible ML Benchmark

A publication-quality, fully reproducible machine-learning benchmark that
extends the paper *"Intelligent Risk Forecasting Systems in the Food Chain:
From Data to Solutions"* from a three-model comparison to a rigorous 15-model
study on the same open IoT cold-storage dataset.

The task is unchanged: **binary spoilage-risk classification** from
environmental sensor data (temperature, humidity, light, CO₂) and fruit type.
No computer vision, no image data, no external datasets — only `Dataset.csv`.

## What this adds over the original study
- **15 models** across four families (linear, tree, boosting, other) under one
  leakage-free pipeline and identical split.
- **Stratified 5-fold CV** with mean / std / 95% CI.
- **Hyperparameter optimisation** (Optuna) for RF, XGBoost, LightGBM, CatBoost.
- **12 evaluation metrics** incl. Balanced Accuracy, MCC, Cohen's κ, PR-AUC,
  Log-Loss, Brier, and timing.
- **Statistical testing**: McNemar, Friedman, Nemenyi (critical difference).
- **Robustness analysis** under simulated sensor drift/noise.
- **Error analysis**, **feature analysis** (SHAP, permutation, RFE, MI, ablation),
  and **computational/deployment profiling**.

## Reproduce everything
Run the notebooks in order (each is also runnable standalone):
```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/01_dataset_audit.ipynb
# ... 02 … 10, or:
for nb in notebooks/*.ipynb; do
  jupyter nbconvert --to notebook --execute --inplace "$nb"
done
```
`src/config.py` fixes the seed (42), split (80/20), and CV folds (5), so runs are
deterministic and all notebooks operate on identical partitions.

## Headline results (held-out test set, positive class = spoilage risk)
- Best models (Extra Trees / XGBoost / CatBoost): Accuracy **0.9982**, F1 **0.9979**, MCC **0.9962**.
- Linear baselines ≈ 0.90 F1; Gaussian NB 0.72 F1.
- Friedman χ² = 65.56 (p = 1.2e-8); the **top-5 ensembles are statistically
  indistinguishable** (Nemenyi CD = 9.59).
- Under realistic sensor drift, best-case mean F1 drops to **0.85** — the clean
  near-perfect accuracy is fragile and must be read as *feasibility*, not a
  deployable figure.

See `reports/experimental_report.tex` for the full write-up (drop-in replacement
for the paper's experimental section) and `reports/paper_improvement_suggestions.md`
for reviewer-style improvements.

## Notes
- Positive class is redefined as **Bad (spoilage risk)** so recall = fraction of
  unsafe storage states detected — the operationally meaningful direction.
- All numbers in the report are generated by the pipeline; none are hand-entered.
